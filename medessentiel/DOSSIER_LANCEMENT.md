# MedEssentiel — Dossier de lancement

## 1. Vision
Marque médicale indépendante, en français, pour (1) étudiants en médecine et internes, (2) grand public. Format : vidéo éducative de 2 à 3 minutes (YouTube, déclinaison verticale Facebook/Shorts). Nom de travail **MedEssentiel** — « La médecine, clairement expliquée. » Nom **non validé** (voir SUIVI D1).

## 2. Trois formats éditoriaux
- **A. Médecine expliquée simplement** — anatomie, physiologie, prévention (ép. 2, 7, 8, 12).
- **B. Révision express** — sémiologie, examens, physiopathologie (ép. 5, 9, 11).
- **C. Urgences et cas cliniques** — signes d'alerte, raisonnement, conduite générale (ép. 1, 3, 4, 6, 10).

## 3. Identité
Bleu médical foncé `#0B2545`, turquoise `#13A8A8`, blanc. Présentateur : avatar HeyGen existant (aucun nouvel avatar). Tons : professionnel, pédagogique, sans dramatisation. Étiquette systématique : « Information éducative — ne remplace pas une consultation. »

## 4. Garde-fous éditoriaux (obligatoires)
1. Aucune source inventée ; chaque chiffre relié à `SOURCES.md` (niveau A avant publication).
2. Éducation générale ≠ prise en charge individuelle (mention à l'écran et dans la description).
3. Urgences : décrire les signes d'alerte et dire d'appeler les secours ; pas de conduite thérapeutique à domicile.
4. Aucune donnée patient identifiable ; la marque n'est pas un organisme médical accrédité.
5. Pas de publication automatique : revue scientifique (D4) puis contrôle final.
6. YouTube : respecter la politique sur la désinformation médicale ; déclarer le contenu synthétique/modifié (avatar IA) lorsque l'option l'exige — à confirmer dans YouTube Studio.
7. Aucune dépense sans accord (HeyGen : 454 crédits premium restants).

## 5. Chaîne de production (par épisode)
Claude : recherche + script → contrôle scientifique (Dr Massenat) → HeyGen (avatar existant, voix française privée) → montage (schémas, textes, sources) → publication manuelle YouTube puis Facebook vertical.
Statuts : à rédiger → à vérifier → prêt pour HeyGen → généré → contrôlé → publié.

## 6. Plan 30 jours
- **S1** identité, chaînes, modèle, vidéo pilote (ép. 1 comme pilote).
- **S2** production et vérification de 4 vidéos (ép. 1, 2, 4, 6 proposées : mélange urgence/grand public/anatomie).
- **S3** lancement public, 2–3 publications.
- **S4** analyse (rétention, clics, questions), ajustement, lot 2.
Aucune garantie d'audience. Rythme tenable avant volume.

## 7. KPI du premier mois
Vidéos terminées ; rétention moyenne ; questions/abonnements qualifiés (pas seulement les vues).

## 8. À faire par l'utilisateur (non automatisable ici)
Vérifier disponibilité du nom (YouTube, Facebook, domaine, marque) ; créer chaîne/page ; valider looks HeyGen ; relecture scientifique ; autoriser les dépenses de crédits.
