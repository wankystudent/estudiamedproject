# Recherche — Intoxications : l'essentiel (2026-11-25)

Origine : capture d'une publication tierce « Drugs that save lives in emergencies — Part 06 » (Medical Review). **Visuel, nom et marque non repris** ; contenu refait de façon originale et sourcée.

## Ce que dit la littérature lue (résumés PubMed, niveau A)
| Sujet | Point clé | Source |
|---|---|---|
| Pesticides organophosphorés | Auto-intoxication ≈ 200 000 décès/an dans les zones rurales ; létalité souvent > 15 % ; réanimation précoce (atropine, oxygène, ventilation, liquides) ; rôle des oximes (pralidoxime) **non totalement clair** (bénéfice possible selon pesticide/gravité) ; lavage gastrique seulement une fois le patient stabilisé | Eddleston et al., Lancet 2008, PMID 17706760 |
| Dabigatran (hémorragie) | Idarucizumab : inversion de l'effet anticoagulant (médiane 100 %) chez 503 patients ; arrêt du saignement médian 2,5 h ; mortalité à 90 j ≈ 19 % (patients très graves) | Pollack et al., NEJM 2017, PMID 28693366 |
| Anesthésiques locaux (LAST) | Rare mais potentiellement mortelle ; soins de support + émulsion lipidique IV 20 % ; prévention : écho-guidage, aspiration avant injection, dose minimale | Long et al., Am J Emerg Med 2022, PMID 35777259 |
| Paracetamol | Hépatotoxicité retardée (pic ≥ 3 jours) ; nomogramme de Rumack-Matthew ; N-acétylcystéine = traitement de choix, très efficace donné tôt | Prescott, Br J Clin Pharmacol 2024, PMID 37683599 |
| Opioïdes | Dépression respiratoire, stupeur, coma ; surdose réversible par naloxone ; MOUD réduisent la mortalité (HR 0,52) | Harris et al., JAMA 2026, PMID 41671014 |
| Monoxyde de carbone | Gaz incolore/inodore ; symptômes de la céphalée à l'état critique ; diagnostic par co-oxymétrie ; traitement = oxygène (masque à haute concentration) ; indications de l'oxygène hyperbare controversées | Chenoweth et al., Crit Care Clin 2021, PMID 34053712 |
| Antithrombotiques (hémorragie intracrânienne) | Recommandations GRADE de réversion (héparines, AVK, anti-Xa, thrombine) | Frontera et al., Neurocrit Care 2016, PMID 26714677 |
| Insuffisance hépatique aiguë | Causes dont paracétamol ; transplantation dans ≈ 30 % | Stravitz & Lee, Lancet 2019, PMID 31498101 |

## Conseils grand public (niveau B, sources web : MedlinePlus, Mayo Clinic, Poison.org — à valider, D4)
- Ne pas faire vomir (ipéca abandonné) ; ne pas « neutraliser » avec citron/vinaigre sauf avis d'un centre antipoison ; ne rien donner par la bouche à une personne inconsciente.
- Appeler les secours / le centre antipoison **local** ; garder l'emballage du produit ; appeler les secours si somnolence, perte de connaissance, détresse respiratoire, convulsions.
- OMS (via données en ligne, niveau B) : ≈ 193 000 décès par intoxication non intentionnelle en 2019 ; taux plus élevés dans les pays à revenu faible/intermédiaire ; 20 % des suicides = auto-intoxication par pesticides.

## Non vérifié / à ne pas affirmer
- Protamine ↔ héparine : antidote classique (pratique courante), mais abstract lu ne le détaille pas → niveau NL, D4.
